# Mu-Yang Chen's website

A personal academic website using [Fuwari](https://github.com/saicaca/fuwari) and Astro. It keeps Publications, Notes, Blog Posts, About, and CV, with light/dark mode, an accent-color picker, animated navigation, and Pagefind search.

## Start here

- [Publishing guide](PUBLISH-ON-GITHUB.md): upload the redesign with GitHub Desktop and publish through GitHub Pages.
- [Maintenance guide](UPDATE-YOUR-WEBSITE.md): add posts, notes, and publications; update personal details and images.
- [Image map](CUSTOMIZE.md): which banner, avatar, and cover files to replace.
- [Readable combined guide](WEBSITE-GUIDE.html): open this file in a browser after downloading it.

GitHub Pages uses GitHub Actions to build this repository. The workflow checks pull requests and deploys pushes to master. Edit src/content and public, commit the changes, and push to master to update the website.

## Local development

Use Node.js 24 and pnpm 11.25.0.

```sh
pnpm install --frozen-lockfile
pnpm check
pnpm build
pnpm verify
pnpm preview
```

Use pnpm dev for live editing. Test search with the production preview because its index is generated by the build.

The thesis now appears independently of the former Jekyll category configuration, with separate paper and slides PDF links. Defense.pdf was exported from the original PowerPoint.
